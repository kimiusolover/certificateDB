# certificateDB

[English README](README.md)

`certificateDB` は、無線機器の認証・規制に関する根拠を、対象機種の正確な版と公式一次資料へ追跡可能な形で記録する台帳です。

ここにある記録は、規制当局のデータベース、法的助言、無線送信の許可、ファームウェア設定の代替ではありません。`verified` は根拠と機種同一性が独立にレビュー済みであることを表すだけで、運用・送信の許可を意味しません。

## 方針

- 公式の一次資料と、取得日時・ハッシュ・該当箇所を対応付けます。
- ラベル写真、OCR、検索抜粋、非公式な転載は候補発見の補助であり、認証事実の証明には使いません。
- 未知の値は未知のまま保持し、別機種・別リビジョンから推測しません。
- 消費側は、認証根拠に加えて正確なハードウェア、校正値、ドライバー、現行法令を独立に確認し、不足時は停止します。

詳細は [POLICY.ja.md](POLICY.ja.md)、機械可読な契約は `schemas/` を参照してください。
